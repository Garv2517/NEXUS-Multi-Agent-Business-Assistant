# NEXUS Frontend

React + Vite frontend for the NEXUS AI-103 Multi-Agent Business Assistant.

Main routes:

- `/` Overview
- `/assistant` Assistant + Agent Trace
- `/sales` Sales
- `/inventory` Inventory
- `/hr` People Management
- `/performance` Business Performance
- `/risk` Insights & Risk
- `/forecast` Forecasting & Planning
- `/activity` Activity
- `/about` About NEXUS

## Run

```powershell
npm.cmd run dev
```

## Production build

```powershell
npm.cmd run build
```

All internal feature navigation uses React Router and remains in the same browser tab.
